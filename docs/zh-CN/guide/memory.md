# 学习记忆

Minih-Agent-Desktop 把三类长期上下文分开保存：

- **项目指令**（`AGENTS.md` 等）是代理必须遵守的规则，属于工作区里的文件。
- **项目记忆**（项目菜单里的固定编辑器）是你自己维护的全文，每次会话启动都会加载。
- **学习记忆**是一组短的、带日期的记录：偏好、反馈、事实与引用，来自更早的对话。新会话启动时
  会带上它们的有界索引，代理也可以按需检索其余部分。

## 让代理记住一件事

直接说想保留什么——「记住我喜欢简短的中文回复」「记一下这个网关每周五发布」。代理会调用
`MemoryRemember`，它先请求你的批准，随后对话里出现一张回执，显示保存了什么，以及它作用于本项目
还是作用于你的所有项目。

回执提供两个动作：

- **编辑**改写措辞。若别处已先改动同一条记录，你会被告知并重新加载列表，而不是覆盖。
- **撤销**删除该记录。删除不是隐藏：文本被擦除，代理也无法被说服重建它——无论是你要求，还是
  它读到的文件里写着什么。如果你确实想让它回来，被删除记录的回执上提供「仍然记住」，只有你能点。

记录从**下一个**会话开始生效。当前对话保留它启动时的那份记忆快照，因此让代理记住某事永远不会
打扰它已有的内容。

看起来像凭据的记录——API key、token、私钥、URL 里的密码——会被拒绝，被拒文本不会被存储、
记录到日志，也不会回显。

## 查看与清理

在「设置 → 项目档案」中，从项目行的菜单打开「学习记忆」，它就在「项目记忆」旁边。设置页为作用于
你所有项目的记录提供同一个管理界面。

管理界面列出某个作用域的记录，可按键值与状态过滤，并对每条执行编辑、归档、恢复或删除。归档只是
隐藏、不会遗忘，因此还能回来；删除是永久的。记录来自某个对话时，管理界面可以打开那个对话。

固定记忆编辑器是另一个界面，行为保持不变；两者互相链接。

## 本机用量

管理界面底部显示学习记忆**在本设备**上的运行状况：上次会话启动时索引有多大、你保留与丢弃了多少
建议及其比例、删除多少次拦下了写入、以及今天抽取花了多少。这些数字属于本机：不会上传到任何地方，
也不随配置同步传输，因此另一台设备显示它自己的数字。

## 关闭它

- **设置 → 使用学习记忆**会隐藏会话启动索引与全部学习记忆工具。不会删除任何内容，重新打开即可
  恢复。该开关随配置同步，因此在你的设备间保持一致。
- **会话菜单 → 不要从这次对话学习**会让这次对话不参与抽取，包括已经在等待启动的运行。
- **设置 → 自动学习**默认关闭，并且在你选定**学习模型**之前无法开启。每次运行都会消耗该模型的
  额度，所以这个开关由你决定；旁边会写明这一点。

## 自动学习（可选）

开启后，对话结束（空闲十分钟）或压缩之后，应用会读取你自己写的消息，请所选模型提出值得保留的
记录。除此之外不会有任何内容外发：工具结果与代理的回复从不发送，请求上限是 16 KiB 的你自己的
原话，加上最近一次压缩摘要。

返回的是**建议**，而不是记忆。打开管理界面：「建议」页签会显示每条提议的内容、类型、作用域，以及
它出自你的哪句话。**保留**使它成为记忆；**丢弃**会擦除它并记下这份证据已被拒绝，因此不会再被
提议。该页签只显示一个安静的计数，从不打断你。

每次运行都会消耗你所选模型的 token。**每日 token 预算**为其上限，**今日已用**显示当前用量；
达到上限后自动学习暂停到明天，该行也会如此说明。学习相关设置只属于本设备：另一台机器会选择它
自己的模型与预算。

## 同步

当 opt-in 的**记忆**类别打开时，学习记忆会随**设置 → 云同步**一起传输，与固定项目记忆完全一致：
你保留的两种作用域的记录，以及让已遗忘记录无法回流的删除屏蔽记录。建议、学习游标与上面的计数留在
产生它们的设备上。你在这里做的删除在那边同样生效，因此同一句话无法在另一台机器上从同一段对话被
重新学回来。

两台设备各自写下的同一句话最终只有一条记录，而不是两条，因为记录的身份是它自己的文字，而不是保存
它的设备。

**同一 vault 的所有设备都必须运行本版本或更新版本。** 旧构建的设备读不到携带学习记忆的修订，因此
它会停止同步（以及恢复），直到升级。开启记忆类别之前，请先升级所有设备。

## 代理能用它做什么

除了启动时那份简短索引，代理还有三个工具：

- `MemorySearch` 读取作用于本项目与你的记录。
- `SessionHistorySearch` 检索本项目更早的对话并返回短片段。读取其他项目的对话是另一个需要批准的
  独立动作。
- `MemoryRemember` 保存一条新记录。

三者都把返回内容当作带日期的上下文而非指令：代理应先对照当前工作区核实涉及的代码与环境，再采信；
并且以你当前的请求优先于更早的记录。
