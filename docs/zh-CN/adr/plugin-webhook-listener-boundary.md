# ADR：Webhook 监听边界与隔离的令牌展示

- **状态**：已接受实施
- **关联**：[插件宿主能力](/zh-CN/adr/plugin-host-capabilities)、ADR 0142、ADR 0008 D009
- **规范**：[插件 API](/zh-CN/spec/07-plugins/03-plugin-api)、
  [插件安全](/zh-CN/spec/07-plugins/04-plugin-security)、
  [数据存储](/zh-CN/spec/03-runtime/04-data-storage)

## 背景

入站 webhook 需要接收本地局域网或 EasyTier 网络的事件，监听与令牌由宿主保管。
部分专用覆盖网络使用公网地址段。插件 renderer 扩展与主窗口共用执行环境，能够
访问通用 IPC，因此返回令牌的主窗口 IPC 不是隔离的设置界面。

## 决策

1. 局域网模式绑定 IPv4 `0.0.0.0`，支持时同时绑定 IPv6 `::`；仅本机模式绑定
   `127.0.0.1`。默认端口 37124；占用时选择随机端口并持久化。仅当启用的插件
   已获授权且声明接收口时运行监听器。
2. 读取请求体之前，只允许回环、RFC1918、IPv4 链路本地、CGNAT、IPv6 链路本地、
   ULA 及本机网卡的直连子网（IPv4 前缀至少 /16，IPv6 至少 /48）；其他来源返回
   `403`。这是来源地址过滤，**不能证明请求经过某一网卡，也不能保证完全不暴露
   公网**：本机直连的公网子网也可能匹配。
3. 传输使用明文 HTTP。安装和设置警示须说明令牌及请求内容可能被截获；用户应使用
   可信网络，或自行配置安全传输和防火墙。
4. 令牌由宿主生成并存储在密钥库，使用常量时间比较；插件 API 和事件不返回令牌。
   主窗口 IPC 只打开系统原生对话框，不返回令牌；用户在对话框中明确操作才显示、
   复制或轮换令牌，插件 renderer 代码不在对话框中运行。ADR 0008 D009 仍然适用：
   原生插件入口不是操作系统沙箱，同用户权限下的恶意插件不在此隔离保证之内。
5. 已接受请求的方法、脱敏头部和正文先写入宿主私有 sidecar，再写元数据；持久化后
   返回 `202`，插件处理完成后单独确认。未确认事件在重启或重载后补投，保留七天；
   保证至少一次，不保证恰好一次。

## 后果

默认支持局域网和覆盖网络发送方，主窗口 IPC 不暴露令牌。来源过滤与令牌不能代替
TLS、防火墙或不可信原生插件的沙箱。文件删除和数据库删行之间崩溃时，启动先重试
过期清理再补投；启动时也会删除无行引用的宿主生成 sidecar。
