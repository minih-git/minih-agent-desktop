解释这段 React 渲染逻辑
这张截图里的组件为什么会渲染两次？

原因：开发模式下的 StrictMode

React 18+ 在开发环境会故意调用两次组件函数和 effect，用来暴露副作用问题：

  • 只在开发模式发生，生产构建不会
  • effect 会执行 setup → cleanup → setup
tsx
useEffect(() => {
  const id = setInterval(tick, 1000);
  return () => clearInterval(id);
}, []);
